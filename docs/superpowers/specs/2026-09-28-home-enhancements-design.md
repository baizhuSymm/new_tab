# 首页效率组件增强规格

- 日期：2026-09-28
- 状态：待用户审阅
- 基础规格：`2026-09-26-personal-new-tab-design.md`
- 视觉方向：用户选择第一版布局，并补充移除日历、网站分组使用Tab页签。

## 1. 目标与边界

在现有个人新标签页上增加轻量的日期、计算和个性化能力，让用户打开首页即可查看重要日期、快速计算，并按个人习惯整理首页。继续使用现有 React + TypeScript + Vite、CSS Modules 和本地存储架构。

本规格是第一版规格的增量，不取代其中已有的搜索、OpenClaw入口、快捷网站、待办、便签、天气和最近打开行为。

明确范围：

- 日期功能只做倒数与纪念日，不制作日历组件、日期网格或日历视图。
- 保留现有唯一的 OpenClaw 入口；不增加其它 AI 工具入口，也不改变 OpenClaw 连接方式。
- 计算器、日期列表、快捷网站、待办和便签均为本地功能，不要求账号、后端或云同步。
- 不做在线组件商店、远程壁纸服务、系统通知或日历账户同步。

## 2. 视觉与首页结构

![首页增强方向：无日历，网站分组使用页签](./assets/home-enhancements-concept.png)

沿用既有首页视觉基准：窄侧栏、城市壁纸与时间天气、搜索栏、紧凑 OpenClaw 入口、白底与绿色强调色。图片用于表达布局，不代表图片中的示例事件、站点内容或虚构入口需要照搬。

- 搜索栏下方仍仅显示现有 OpenClaw 入口；对话区按现状点击后展开。
- 倒数/纪念日与计算器作为可管理组件进入首页；默认布局优先展示近期日期列表，计算器占用更紧凑的区域。
- 现有待办与快速记录继续可见；网站快捷方式保留现有分组和站点数据。
- 网站分组控件从下拉框改为网站区标题下方的横向 Tab，活动分组有清晰选中态；Tab 紧邻对应网站图标网格。
- 保持当前紧凑间距原则，避免新增功能把首屏挤成卡片墙。具体断点与组件尺寸在实施计划中核对现有响应式布局后确定。

## 3. 功能与交互

### 3.1 倒数与纪念日

- 首页组件以列表显示用户创建的日期事项；支持添加、编辑、删除和排序。
- 每项包含标题、目标日期、类别（倒数或纪念日）以及可选颜色/图标标识。
- 未来日期显示剩余天数；过去日期显示已过去天数。目标日当天显示“今天”，不显示负数倒计时。
- 纪念日按年重复，显示自原始日期累计的天数及距离下次周年的天数；2月29日遇到非闰年时按2月28日计算。
- 日期按最近目标时间排序；已过去日期仍可保留为纪念日，不自动删除。
- 空列表提供直接新增入口；删除有确认或可撤销反馈。
- 仅按本地日历日期计算天数，不创建闹钟、不发送通知，也不访问外部日历服务。

### 3.2 计算器

- 提供加、减、乘、除、百分比、小数点、正负切换、清除和结果操作。
- 支持鼠标/触控按钮及键盘输入；提供清晰的当前输入和结果状态。
- 除数为零、连续运算、重复小数点和超长结果均有确定且不崩溃的行为。
- 不使用 `eval` 执行表达式；不保存计算历史，不接入外部计算服务。
- 可从组件中心显隐并参与首页布局调整。

### 3.3 主题与壁纸库

- 提供浅色和深色主题；颜色通过现有 CSS Variables 统一切换，并保留站点图标的原始品牌色。
- 壁纸选择面板区分内置壁纸与用户本地上传壁纸；可选择、预览并调整裁切位置。
- 用户上传的壁纸保存在本地；错误格式、尺寸过大、压缩失败或存储空间不足时提示原因，并保留当前正在使用的壁纸。
- 原有城市壁纸和单张自定义壁纸数据通过迁移保留，不因升级丢失。
- 不加载远程壁纸推荐，不增加天气以外的网络请求。

### 3.4 组件中心与布局

- 提供清楚的“添加小组件/管理组件”入口，列出可用组件和当前显示状态。
- 可选组件包括现有快捷网站、待办、便签、最近打开，以及本规格新增的倒数/纪念日和计算器。
- 支持显示/隐藏、拖动排序及在现有左栏、右栏、整行槽位间移动；提供键盘可操作的移动控制。
- 编辑状态可保存或取消；取消恢复进入编辑前布局。恢复默认布局仅重置布局，不删除业务数据。
- 搜索栏、壁纸/时间天气和 OpenClaw 入口不纳入可拖动组件集合。
- 不支持任意坐标定位、重叠、嵌套组件或用户编写组件。

### 3.5 网站分组 Tab

- Tab 名称来自现有 `ShortcutGroup`，顺序沿用分组排序；切换只过滤当前快捷网站，不修改分组或站点数据。
- 活动分组默认沿用现有首页选择逻辑；本阶段不要求跨刷新记住最后选中的分组。
- 编辑模式中的新增、重命名、删除分组和站点移动行为继续有效，入口仍在网站区管理控件中。
- 窄屏横向空间不足时，Tab 可横向滚动且保持触控和键盘可用，不造成页面横向溢出。
- 使用语义化 Tab 交互：可访问名称、选中状态、键盘切换和正确的焦点管理。

## 4. 数据与兼容

新增本地实体：

- `CountdownEvent`：稳定 id、标题、目标日期（本地日期字符串）、类别、排序值及更新时间。纪念日类别按年重复，普通倒数事项为单次日期。
- 设置新增主题标识；壁纸记录扩展为可保存多个本地资产并关联当前选中项。
- 布局模块标识增加倒数/纪念日和计算器，并增加必要的布局版本迁移。

兼容要求：

- 迁移幂等；不得清空或覆盖现有网站、分组、待办、便签、壁纸及布局。
- 旧布局中的未知或新增模块应安全回退到可用默认布局，并保留可迁移的旧数据。
- 继续遵循第一版按实体独立保存的原则，更新日期列表或主题不得覆盖其它数据。
- 普通网页预览与扩展的存储适配行为保持一致，数据仍彼此独立。

## 5. 验收标准

1. 首页没有日历组件、日期网格或日历视图；可新增和管理倒数/纪念日并正确显示未来、当天和过去日期。
2. 计算器覆盖四则运算与基本输入边界，可通过鼠标、触控和键盘操作，不执行任意脚本。
3. 主题切换后刷新仍生效；切换壁纸不会丢失旧的自定义壁纸或改变裁切设置，存储失败时保留当前选择。
4. 组件中心可以增删显示、排序和跨栏移动新旧组件；保存、取消、恢复默认的语义正确，业务数据不受布局重置影响。
5. 网站分组显示为横向页签；切换分组、维护分组、移动网站、拖拽网站及窄屏键盘操作均正常。
6. 原有 OpenClaw、搜索、天气、待办和便签流程无回归；不出现额外 AI 工具或未经请求的外部服务。
7. 在 1440×1024、1024×768、390×844 和 320px 宽度验证首屏层级、内容密度、Tab 可用性、组件溢出与页面横向滚动。
8. 覆盖数据迁移、日期边界、计算器运算、布局保存与取消、主题/壁纸选择和快捷网站分组的自动化测试，并通过类型检查与生产构建。

## 6. 明确不做

- 日历组件、日历网格、第三方日历同步。
- 多 AI 工具目录或在此规格中实现 OpenClaw 对话连接。
- 云同步、账号、后端、在线壁纸库、组件市场和系统提醒。
- 计算历史、高级科学计算和任意数学脚本。

本规格通过用户审阅后，再编写分步实施计划并确认执行方式；之后才进入代码实现。实施时先核对存储迁移、布局模块注册和响应式规则，再分别实现与测试各组件。
