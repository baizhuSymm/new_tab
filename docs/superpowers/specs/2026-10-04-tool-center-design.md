# 工具栏与工具中心设计规格

- 日期：2026-10-04
- 状态：待用户审阅
- 视觉基准：用户选定的方案 2，经修订后明确为独立工具中心页面。

![独立工具中心页面设计图](./assets/tool-center-selected.png)

## 1. 目标与范围

将搜索栏下方现有的 OpenClaw 入口改为可复用工具栏。首页只显示用户已添加的工具按钮，以及始终位于末尾、尺寸相同的“添加”按钮。点击工具仍在工具栏下方展开对应操作区；点击“添加”进入独立的工具中心页面。工具中心集中展示可用工具，负责浏览、预览、添加和移除。

首版内置 OpenClaw 聊天、计算器、翻译、文档转换四个示例。四者的页面和交互状态需要可展示、可操作，但除现有 OpenClaw 打开本机控制台的行为外，不要求真实聊天、计算、翻译或文件转换。任何尚未接入的能力必须明确标注，不显示伪造的成功结果。

这次需求取代 `2026-09-28-home-enhancements-design.md` 中“仅保留 OpenClaw、不增加计算器或多工具目录”的旧范围约束；该规格的其它首页、布局和本地数据要求继续适用。

## 2. 页面与视觉

### 首页

- 搜索栏下保留现有图标在上、文字在下的紧凑按钮样式，桌面端单个按钮沿用约 78×50px 的尺寸；已添加工具按保存顺序显示。
- “添加”按钮与工具按钮等大，始终位于工具栏末尾。窄屏时工具按钮在单行内横向滚动，“添加”按钮仍可见；工具栏不造成页面横向溢出。
- 一次最多展开一个工具操作区。点击当前工具可收起；点击另一工具切换下方操作区。展开区沿用现有 OpenClaw 面板的白底、细边框和绿色强调色。
- 首页原有网站、日程、待办、便签等模块保持在工具栏或展开区之后。工具栏不纳入现有“编辑布局”的模块显隐与排序。

### 独立工具中心

- 工具中心作为独立 `AppView`，可从首页“添加”按钮和侧栏工具中心入口进入。侧栏明确显示当前页面；提供“返回首页”。
- 页面沿用现有侧栏、壁纸、时间天气、全局搜索栏和主题变量。工具中心页面**不显示首页工具栏**，也不显示首页业务模块。
- 主体采用选定设计图的三栏结构：左侧类别筛选，中间工具列表，右侧所选工具的交互预览。首版类别为“全部 / 常用 / 文本 / 文件”；“常用”显示已添加工具，“文本”显示翻译，“文件”显示文档转换。类别只筛选工具，不改变添加状态。
- 每个工具行显示图标、名称、简短说明和“添加到首页”或“移除首页”操作。已添加状态清晰可见。选择工具行只更新右侧预览；添加与移除是独立操作，避免误触。
- 添加或移除成功后留在工具中心，立即更新行内状态与首页工具选择；返回首页时即可看到结果。工具说明描述用途与演示内容，不承诺尚未接入的实际能力。
- 窄屏时类别变为可横向滚动的选择条，工具列表为单列，预览移至列表下方；不出现横向页面滚动。深色主题使用现有 CSS 变量。

## 3. 工具交互

| 工具 | 首页展开区与工具中心预览 | 首版行为 |
| --- | --- | --- |
| OpenClaw 聊天 | 复用现有标题、连接状态和操作区 | 明确显示“本页未接入”；“打开 OpenClaw 控制台”继续打开 `http://127.0.0.1:18789/`。消息输入保持不可发送。 |
| 计算器 | 数字与运算符键盘、表达式显示区 | 按键可更新表达式；执行计算时提示“计算功能尚未接入”，不展示计算结果。 |
| 翻译 | 源/目标语言选择、可输入文本及结果区域 | 选择和输入可改变界面状态；执行翻译时提示“翻译服务尚未接入”，不展示伪造译文。 |
| 文档转换 | 格式选择、文件选择及文件名展示 | 可选择本地文件并显示文件名；执行转换时提示“转换功能尚未接入”。文件不读取内容、不上传、不保存。 |

工具中心预览复用各工具的操作区组件，旁边标注“交互示例”。首页和工具中心共享同一工具定义，避免名称、图标和状态不一致。离开当前页面后，未提交的演示输入无需持久化。

## 4. 数据与组件边界

- 使用代码内的静态工具注册表管理稳定 ID、名称、图标、类别、说明和操作区组件。四个 ID 固定为 `openclaw`、`calculator`、`translator`、`document-converter`。首版不执行用户提供的脚本，也不下载远程工具。
- 新增独立的本地 `toolSelection` 记录，格式为版本号与有序工具 ID 列表。默认列表仅包含 `openclaw`，使现有用户升级后仍看到原入口。
- 添加工具时将其 ID 追加到列表；移除工具时删除 ID。重复添加不产生重复项。首页按列表顺序展示；首版不提供手动排序控件。
- 从旧数据加载时，如果记录不存在，则使用默认列表，不改写其它设置或业务数据。未知工具 ID 不渲染，仍保留原始记录直到用户主动保存工具选择，便于未来版本兼容。
- 工具选择经现有仓库与网页/扩展存储适配器读写，采用同一读写锁和错误反馈机制。保存失败时保留原有已添加状态，并显示现有应用错误提示。
- 如果用户移除当前展开的工具，首页立即收起该操作区。工具中心的当前预览选择与工具是否已添加相互独立。

## 5. 可访问性与验收

- 首页工具按钮使用可访问名称、`aria-expanded` 和关联操作区；键盘可打开、切换和收起。返回首页后焦点有明确落点。
- 工具中心类别、工具列表和添加/移除操作都可用键盘操作；保存状态变化有可读反馈。
- 迁移后首页默认保留 OpenClaw；添加计算器后首页出现对应按钮，刷新后仍在；移除后按钮消失。工具中心始终列出四个内置示例。
- 首页工具栏与工具中心页面严格分离：工具中心不渲染工具栏，首页不渲染工具目录。
- OpenClaw 原有打开本机控制台行为、搜索、主题、首页布局和其它模块无回归。
- 验证 1440×1024、1024×768、390×844 和 320px 宽度；检查按钮行、固定可见的“添加”、展开区及工具中心三栏到单栏的变化。
- 自动化覆盖工具选择的存储默认值与失败处理、添加/移除、首页展开切换、独立页面导航，以及网页与扩展的关键流程；运行类型检查和生产构建。

## 6. 本阶段不做

- 实际 OpenClaw 聊天连接、计算引擎、翻译服务或文档格式转换。
- 在线工具商店、第三方插件加载、用户自定义工具代码、账号同步或工具数据云存储。
- 将工具中心合并到首页，或将工具栏纳入现有首页模块布局编辑器。
